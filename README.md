# Student Management System

A command-line application built with Python and SQLite that demonstrates CRUD operations and basic database management.

## Features

- Add Student
- View Students
- Update GPA
- Delete Student
- Input validation
- SQLite database

## Technologies

- Python
- SQLite
- Git

## How to Run

```bash
python main.py
```
